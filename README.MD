## Introduction
Ceci a été développé dans le but de facilité la vie au remplacement des charactères `CRLF` et `LF`
spécifique aux fichiers de la traduction FR de Heroes 3 HotA.

## Comment exécuter le programme
1. récupéré le fichier `CorrecteurDeFichier.jar`
2. le mettre dans un dossier avec les fichiers `.txt` à corriger
3. ouvrir un invite de commande windows au même emplacement
4. exécuté la commande (vous devez avoir installé [Java](https://www.java.com/en/download/manual.jsp) avant) : 
```shell
java -jar CorrecteurDeFichier.jar
```

Vous obtiendrez ensuite des fichiers corrigé. ⚠️Attention⚠️ certains fichier peuvent ne pas être complètement corrigé.  
Il va falloir repasser derrière pour confirmé. Vous aurrez à votre disposition un fichier `_resultat.txt` qui vous donneront les informations pour comparer.
