## Introduction
Ceci a été développé dans le but de facilité la vie au remplacement des charactères `CRLF` et `LF`
spécifique aux fichiers de la traduction FR de Heroes 3 HotA.

## Comment exécuter le programme
1. récupérer le fichier `CorrecteurDeFichier.jar`
2. le mettre dans un dossier avec les fichiers `.txt` à corriger
3. ouvrir un invite de commande windows au même emplacement
4. exécuter la commande (vous devez avoir installé [Java](https://www.java.com/en/download/manual.jsp) avant) : 
```shell
java -jar CorrecteurDeFichier.jar
```

Vous obtiendrez ensuite des fichiers corrigés. ⚠️Attention⚠️ certains fichiers peuvent ne pas être complètement corrigés.  
Il va falloir repasser derrière pour confirmer. Vous aurez à votre disposition un fichier `_resultat.txt` qui vous donnera les informations pour comparer.
